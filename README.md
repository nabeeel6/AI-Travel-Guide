# Janko AI Travel Guide

An AI-powered travel guide that provides AI-generated information and audio guides for selected destinations.

## Features

- Explore selected travel destinations
- AI-generated destination information
- Audio travel guides
- Multiple language support
- Male voice options
- Responsive web interface

## Technologies Used

- HTML
- JavaScript
- Tailwind CSS
- Python
- Flask
- Google Gemini API
- Murf AI API
- REST API
- Git & GitHub
- Render
